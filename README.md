# PRODIGY_DS_01

****************** DATA SCIENCE ******************

Task - 01  Prodigy InfoTech Data Science Internship


This repository contains a Python implementation to visualize the distribution 
of categorical and continuous variables using bar charts and histograms.


The project demonstrates data loading, preprocessing, and visualization 
using Pandas and Matplotlib, following best practices for data analysis.


------- Key Features:

 1. Bar chart for categorical data (e.g., Gender distribution)

 2. Histogram for continuous data (e.g., Age distribution)

 - Clean, readable, and ready-to-submit code

 - Executed using VS Code and Python
